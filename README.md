# جدول خطباء الجمعة

برنامج لتوزيع خطباء الجمعة على المساجد كل شهر هجري، مبني على إجابات استبيان مسؤول الدعوة.

## بيعمل إيه

- **توزيع تلقائي بضغطة**، بيراعي:
  - الخطيب الثابت (للشهر كله أو لجمعة معينة).
  - الحد الأقصى لكل خطيب.
  - إن الخطيب ما يخطبش في نفس المسجد مرتين في الشهر.
  - إن الخطيب الجديد ما يروحش مسجد كبير.
  - طلبات المساجد (يفضّل / يتجنب).
  - العدل في التوزيع، والتنويع عن الشهور اللي فاتت.
  - لما يكون فيه عجز، المساجد الكبيرة بتاخد الأولوية.
- **الاعتذارات:** لما خطيب يعتذر، البرنامج بيرتب البدلاء من الأنسب للأقل، وبيجهز رسالة واتساب للبديل.
- **صفحة خاصة لكل خطيب** (`/p/...`) من غير تسجيل دخول، يأكد منها أو يعتذر.
- **الإرسال على واتساب:** جدول الشهر لكل خطيب، وتذكير الخميس، وجداول المساجد.
- **التقرير الشهري:** عدد جمعات كل خطيب، ومين أكد ومين اعتذر، وتصدير إكسل وطباعة.
- **بداية الشهر الهجري** محسوبة تلقائيًا، وتقدر تقدّمها أو تأخرها يوم وتختار 29 أو 30 يوم حسب دار الإفتاء.
- **شغال على الموبايل والكمبيوتر**، والواجهة عربي بالكامل.

## التشغيل لأول مرة (مرة واحدة بس)

1. **الجداول ونقل البيانات:** من Supabase افتح SQL Editor ثم New query، والصق محتوى `supabase/01_new_schema.sql` واضغط Run.
   - البيانات القديمة بتتنقل للجداول الجديدة.
   - الجداول القديمة مش بتتمسح، وبتفضل نسخة احتياطية.
2. **حساب المسؤول:** من Supabase افتح Authentication ثم Users ثم Add user، واعمل بريد وكلمة مرور.
   - من Authentication ثم Sign In / Providers اقفل **Allow new users to sign up**.
3. **قفل البيانات:** افتح `supabase/02_security.sql`، وغيّر `admin@example.com` لبريد المسؤول، وشغّله في SQL Editor.
   - بعدها محدش يقدر يقرا أو يعدّل البيانات غير المسؤول.
   - صفحات الخطباء بتفضل شغالة.

## تجربة البرنامج من غير بيانات حقيقية

افتح الرابط وفي آخره `?demo`، أو دوس "جرّب البرنامج ببيانات تجريبية" من شاشة الدخول. البيانات التجريبية بتتحفظ في المتصفح بس.

## للمطور

```bash
npm install
npm run dev      # تشغيل محلي
npm test         # اختبارات محرك التوزيع والتاريخ الهجري ونصوص الرسائل
npm run lint     # فحص TypeScript
npm run build
```

- **التقنيات:** React 19 + Vite + Tailwind v4، والبرنامج بيكلم Supabase مباشرة من المتصفح. Vercel بيقدّم الصفحات بس.
- **الكود:**
  ```
  src/
  ├── data/            طبقة البيانات: SupabaseRepo (الحقيقي) و LocalRepo (التجريبي)، والـ store والـ selectors
  ├── lib/
  │   ├── engine.ts    محرك التوزيع وقواعده
  │   ├── hijri.ts     التاريخ الهجري وجمعات الشهر
  │   ├── messages.ts  نصوص رسائل واتساب (صيغة رسمية + توقيع المسؤول)
  │   ├── share.ts     إرسال الملفات: قايمة المشاركة على الموبايل، وتنزيل + فتح المحادثة على الكمبيوتر
  │   ├── whatsapp.ts  الأرقام وروابط wa.me
  │   └── pdf/         writer (كاتب PDF) · sheet (رسم الورقة) · documents (جدول الخطيب/المسجد، التكليف، التذكير)
  ├── components/      مكونات مشتركة (SendActions: أزرار "إرسال مع PDF" ونص فقط ونسخ)
  ├── ui/              عناصر الواجهة الأساسية
  ├── auth/            تسجيل دخول المسؤول
  ├── layout/          الإطار والقوائم
  └── pages/
      ├── schedule/    جدول الشهر: الصفحة، نافذة التكليف، نوافذ الشهر، الاعتذارات
      ├── messages/    الإرسال والتذكير (الخطباء، تذكير الخميس، المساجد)
      ├── Portal.tsx   صفحة الخطيب (من غير تسجيل دخول)
      └── ...          باقي الصفحات
  supabase/            ملفات SQL
  ```
- **المتغيرات:** `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` اختيارية، وقيمها موجودة في `.env.example`.
